Обозначения на графике

Каждый кадр — поле вертикальной скорости w(x, z). Горизонтальная ось — x, км; вертикальная — z, км.

  • w(x,z) поле вертикальной скорости (заливка). Красный — восходящий поток, синий — нисходящий, белый — покой. Цветовая шкала внизу графика пересчитывается для каждого кадра.
  • qc изолинии облачной воды (зелёные сплошные), уровни 0.5 / 1.0 / 2.0 г/кг. Показывают ядро облака.
  • qr изолинии дождевой воды (синие пунктирные), уровни 0.05 / 0.1 / 0.2 г/кг. Появляются под облаком — начало осадков.
Что происходит со временем
  1. t = 0 с — тёплый пузырь в покое, поле однородно.
  2. Всплытие — пузырь поднимается, формируется восходящий поток w.
  3. Растекание — по достижении уровня нейтральной плавучести воздух растекается горизонтально, образуется «гриб».
  4. Облако — на высоте конденсации появляются зелёные контуры qc.
  5. Осадки — при достаточном qc включается автоконверсия, появляются синие пунктиры qr под облаком.
Формулы модели (2D) — 8 соотношений

Те же 7 соотношений, что в 1D, плюс уравнение неразрывности и горизонтальная составляющая движения.

1. Уравнение состояния (диагностика Exner)

π = (ρ · Rd · θv / p0)Rd/cpd Exner-функция; задаёт поле давления.

2. Виртуальная потенциальная температура

θv = θ · (1 + 1.608 · qv) / (1 + qv) Учёт влажности в плавучести.

3. Насыщение (формула Тетенса, над водой)

es(T) = e0 · exp[(Lv/Rv) · (1/T0 − 1/T)]
qsat(T, p) = ε · es / (p − es) e0 = 611 Па, T0 = 273.15 K, ε = 0.622.

4. Конденсация / испарение

Δqc = max(qv − qsat, 0)
Δθ = (Lv / cpd) · Δqc / π Избыток пара переходит в qc, выделяется скрытое тепло.

5. Уравнение движения (2D, вертикаль и горизонталь)

∂w/∂t = −cpd · θv · ∂π′/∂z + g · (θv − θref) / θref
∂vn/∂t = −cpd · θv · ∂π′/∂x Вертикаль — с плавучестью; горизонталь — только градиент давления. vn живёт на вертикальных гранях ячеек.

6. Уравнение неразрывности

∂ρ/∂t = −∇·(ρv) = −∂(ρ·vn)/∂x − ∂(ρ·w)/∂z Замыкает систему: изменение плотности связано с дивергенцией потока массы.

7. Турбулентность (Смагоринский + Ri-подавление)

Km = (Cs · Δ)2 · |S| · max(0, 1 − Ri/Ric)
Ri = N2 / |S|2,   N2 = (g/θref) · ∂θv/∂z Cs = 0.15, Ric = 0.25. В 2D-версии пока не встроена (см. раздел «Ограничения»).

8. Автоконверсия qc → qr и осаждение

dqr = coef · max(qc − qc,crit, 0) · dt
∂qr/∂t + Vt · ∂qr/∂z = 0,   Vt = 5 м/с qc,crit = 5·10−4 кг/кг, coef = 10−3 с−1.
Допустимые пределы переменных (2D)

В 2D жёстче требования к dt (CFL по горизонтали) и к max|w| (горизонтальная сходимость усиливает поток).
